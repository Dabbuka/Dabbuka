### Homelabbing
I have a homelab system composed of two PCs.

1. **Proxmox Server:**
   An old gaming PC converted into a server PC running Proxmox VE, an open-source virtualization platform and a bare-metal hypervisor. It is responsible for hosting services for both myself and my friends. These services are divided into appropriate virtual machines hosting Alpine Linux for a minimal footprint on system resources. Some of these services include:
   - Jellyfin
   - Navidrome
   - Modded Minecraft
   - and several others!
2. **NAS:**
   A custom-built NAS that stores whatever I need it to. It also serves as a personal cloud storage for all my devices. WIP with more utility planned for the future.
